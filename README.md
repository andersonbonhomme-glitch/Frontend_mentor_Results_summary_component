<h2 id="aperçu">Aperçu</h2>
<p><strong>Le challenge</strong></p>
<p>Les utilisateurs doivent être capables de :</p>
<ul>
  <li>Il a fallu que je commence par la méthode du Mobile First car il sera plus facile pour la page de s'adapter à un écran d'ordinateur en utilisant les media query</li>
  <li>Que la page puisse être accessible à tous en créer des états comme hover, active et focus</li>
</ul>

<h2 id="mon_processus">Mon processus</h2>
<p><strong>Construit avec</strong></p>
<ul>
  <li>Balises sémantiques HTML5</li>
  <li>Propriétés personnalisées CSS (Variables)</li>
  <li>CSS Flexbox</li>
  <li>CSS Grid</li>
  <li>Approche Mobile-first</li>
</ul>
<p><strong>Ce que j'ai appris</strong></p>
<p>Ce challenge a été une excellente occasion de mettre en pratique mes compétences en CSS, notamment pour la création de dégradés fluides et la gestion des ombres (box-shadow) pour donner de la profondeur au composant.

J'ai également consolidé mes connaissances sur CSS Grid et Flexbox pour structurer parfaitement la carte de résultats à gauche et le résumé détaillé à droite sur la version Desktop.</p>
